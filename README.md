# Mini Market

Sistema de consola en C# para gestionar compras en una tienda.

## Integrantes

- Starling Gonzalez 2026-1546
- Francisco López 2026-1533
- Reyson Rivera 2026-1527

## Descripción

Menú con opciones para calcular el total de una compra con ITBIS,
aplicar descuentos, calcular la devuelta y ver una tabla de precios.

## Cómo ejecutarlo

1. Clonar el repositorio.
2. Entrar a la carpeta del proyecto: `cd MiniMarket`
3. Ejecutar: `dotnet run`
